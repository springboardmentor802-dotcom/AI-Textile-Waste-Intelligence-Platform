# AI Textile Waste Intelligence Platform

## Project Overview

The AI Textile Waste Intelligence Platform is an AI-powered web application developed as part of the Infosys Springboard Internship Program.

The project aims to identify textile waste, manage textile inventory, and promote sustainable recycling using Artificial Intelligence and Machine Learning.

---

##  Objectives

- Identify different types of textile waste
- Manage textile inventory
- Provide recycling recommendations
- Promote sustainable waste management
- Build an AI-powered textile waste classification system
