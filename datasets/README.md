# Dataset Information

## Dataset Name
AITEX Fabric Image Database

## Purpose
This dataset is used for textile fabric defect detection and classification.

## Dataset Structure

- Defect_images/
  Contains images of defective textile fabrics.

- NODefect_images/
  Contains images of normal textile fabrics.

- Mask_images/
  Contains binary masks indicating the exact defect locations.

## Planned Usage

- Image preprocessing
- Defect detection using Computer Vision
- CNN model training
- Waste quality analysis
- Sustainability recommendations

## Total Images

- Normal Images: 140
- Defective Images: 105
